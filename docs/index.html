Natural Voice TTS

A free Windows app that reads any text aloud in a natural-sounding voice — powered by the Kokoro neural model. Smooth pauses, sentences phrased where they really end, and a voice that doesn't sound robotic.

30+ natural voices · GPU-accelerated · runs in the system tray

Reads like a person

Sentences split where they really end — "Dr. Smith", "e.g.", "U.S. Army", "3.14" and "v1.3.0" stay whole — with short, medium and long pauses instead of one flat gap at every boundary.

Pronunciation list

Teach it exact pronunciations for names and brands it gets wrong — your own entries live in a simple JSON file and take effect from the next message, no restart.

Spoken emphasis

Words in bold, italics, or shouted ALL-CAPS ("NOT", "NEVER" — but not acronyms like "API") are said a little slower, higher and louder.

Handles real text

Markdown, code blocks, paths, URLs, dates, versions, units and symbols are all read sensibly. What's on screen is never changed — only the spoken copy.

What's new in 1.3.0

  • Pronunciation list — give names and brands exact pronunciations (for example "Cowork" said as "Co work"). A built-in list ships with the app; your own entries in %APPDATA%\NaturalVoiceTTS\pronunciations.json win over it.
  • Spoken emphasis, on by default — bold, italics and shouted ALL-CAPS words get a gentle lift in pace, pitch and volume.

Earlier 1.2.0 work — correct sentence splitting, natural pauses, a faster start, and sensible reading of markdown, code and symbols — is included too. See the release notes for the full history.

Download & install

No programming required. Download the installer and run it:

  1. Download Natural Voice TTS v1.3.0 (~1.8 GB).
  2. Run NaturalVoiceTTS_Setup_1.3.0.exe. If Windows SmartScreen appears, click More info → Run anyway (the app is unsigned open-source software).
  3. The app starts in the system tray. Select text anywhere and press Ctrl+Win+T to have it read aloud.
Upgrading from an earlier version? Uninstall it first, then run the new installer.

How it works

Natural Voice TTS runs quietly in the system tray. Global hotkeys read your current selection (Ctrl+Win+T), stop playback (Ctrl+Win+X) or pause and resume (Ctrl+Win+Z). You can pick from 30+ American and British voices and set the speed. It also ships an optional MCP server, so tools like Claude Desktop can speak their responses aloud.

Prefer to run from source or build the installer yourself? Full developer instructions are in the README.
